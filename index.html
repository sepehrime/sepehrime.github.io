01. About me

I spent 11 years in oil & gas before moving into software. That time taught me to build things that keep working when the data is messy, the connection is bad, and the person using the tool has no time to read a manual.

Today I build web applications, APIs and database layers with Python (Flask, FastAPI, SQLAlchemy), JavaScript and React. As a former Product Owner I've managed software teams; now I focus on hands-on development and architecture.

I'm currently going deeper into Linux shell scripting and integrating AI models into real applications, with answers that stay traceable rather than magical.
